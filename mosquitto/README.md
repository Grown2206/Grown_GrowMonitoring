# Mosquitto MQTT Broker - Data Directory

This directory contains Mosquitto MQTT Broker configuration and data files.

## Structure

```
mosquitto/
├── config/
│   └── mosquitto.conf    # Main configuration file
├── data/                 # Persistent message storage
└── log/                  # Log files
```

## Configuration

The `mosquitto.conf` is automatically generated by the setup scripts:
- `setup-mqtt.sh` (Linux/Mac)
- `setup-mqtt.ps1` (Windows)
- `docker-compose.yml` (Docker)

## Manual Configuration

To modify MQTT settings, edit `config/mosquitto.conf`:

```bash
nano mosquitto/config/mosquitto.conf
```

After changes, restart Mosquitto:

```bash
# Linux
sudo systemctl restart mosquitto

# macOS
brew services restart mosquitto

# Docker
docker-compose restart mosquitto
```

## Ports

- **1883**: MQTT Protocol
- **9001**: WebSocket Protocol

## Authentication

By default, authentication is **disabled** (`allow_anonymous true`) for easy development setup.

To enable authentication:

1. Create password file:
```bash
mosquitto_passwd -c mosquitto/config/passwd username
```

2. Edit `mosquitto.conf`:
```conf
allow_anonymous false
password_file /mosquitto/config/passwd
```

3. Restart Mosquitto

## Data Persistence

Messages are persisted in `data/` directory. To clear all retained messages:

```bash
# Stop Mosquitto
sudo systemctl stop mosquitto

# Delete data
rm -rf mosquitto/data/*

# Start Mosquitto
sudo systemctl start mosquitto
```

## Logs

Logs are stored in `log/mosquitto.log`.

View logs:
```bash
tail -f mosquitto/log/mosquitto.log
```

## Testing

Test MQTT connection:

```bash
# Subscribe (Terminal 1)
mosquitto_sub -h localhost -t 'test/#' -v

# Publish (Terminal 2)
mosquitto_pub -h localhost -t 'test/topic' -m 'Hello MQTT!'
```
